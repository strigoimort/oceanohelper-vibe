# UI Guidelines

This document defines the UI/UX standards for OceanoHelper. Every page, component, and feature must follow these guidelines to ensure a consistent, intuitive, and premium user experience.

---

# Design Philosophy

OceanoHelper should deliver a premium scientific dashboard experience inspired by modern desktop operating systems.

The interface should feel:

- Clean
- Minimal
- Elegant
- Modern
- Professional
- Responsive
- Scientific
- Fast
- Spacious

Every interface element should have a clear purpose.

Avoid visual clutter.

---

# Layout

Use a consistent application layout across all tools.

```text
+------------------------------------------------------+
| Navbar                                               |
+----------+-------------------------------------------+
| Sidebar  |                                           |
|          |             Main Content                  |
|          |                                           |
|          |                                           |
+----------+-------------------------------------------+
| Footer                                               |
+------------------------------------------------------+
```

Guidelines:

- Consistent navigation.
- Spacious content area.
- Collapsible sidebar.
- Clean page hierarchy.

---

# Visual Style

Prioritize:

- Large whitespace
- Soft shadows
- Rounded corners
- Clear typography
- Consistent spacing
- Subtle borders
- Smooth transitions

Avoid:

- Busy layouts
- Heavy borders
- Excessive gradients
- Flashy animations
- Oversaturated colors

---

# Typography

Preferred font stack:

- SF Pro Display
- Inter
- System UI

Guidelines:

- Clear hierarchy
- Large headings
- Comfortable line height
- Medium font weights
- Excellent readability

Use a single font family throughout the application.

---

# Color System

Use a restrained color palette.

Colors should communicate:

- Primary
- Secondary
- Success
- Warning
- Error
- Information

Accent colors should be used sparingly.

Rely on spacing and typography rather than excessive colors.

---

# Components

All components should share the same design language.

Buttons

- Rounded corners
- Clear hierarchy
- Comfortable padding
- Smooth hover effects

Cards

- Spacious padding
- Soft shadows
- Rounded corners

Forms

- Simple
- Predictable
- Accessible
- Well validated

Tables

- Searchable
- Sortable
- Responsive

Charts

- Clear titles
- Responsive layouts
- Meaningful legends
- Minimal visual noise

Maps

- Maximize visible map area
- Accessible controls
- Consistent marker styling
- Informative popups

---

# Motion

Animations should be:

- Smooth
- Fast
- Purposeful

Use motion only to:

- Improve navigation
- Confirm actions
- Provide feedback

Avoid decorative animations.

---

# Responsive Design

Support:

- Desktop
- Laptop
- Tablet
- Mobile

The experience should remain consistent across all screen sizes.

---

# Accessibility

Every interface should provide:

- Keyboard accessibility
- Visible focus states
- Sufficient color contrast
- Descriptive labels
- Responsive interactions

---

# Consistency

All six tools must share:

- Layout
- Navigation
- Typography
- Colors
- Components
- Buttons
- Cards
- Tables
- Charts
- Interactions

Users should always feel they are using one unified application.

---

# UI Principles

Before adding any interface element, ask:

- Does it improve usability?
- Does it simplify the workflow?
- Is it visually consistent?
- Is it necessary?

If the answer is **No**, do not add it.
