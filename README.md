# OceanoHelper

OceanoHelper is a modern web application for visualizing and analyzing oceanographic, meteorological, and climate data. It provides interactive tools that help users explore marine datasets through maps, charts, and geospatial visualizations.

The platform provides tools for visualizing buoy observations, tracking movement trajectories, analyzing wave conditions, monitoring climate indices, and exploring oceanographic parameters on interactive maps.

## Vision

To build an accessible, modern, and interactive oceanographic platform that simplifies marine data visualization and analysis.

## Target Users

- Oceanographers
- Marine researchers
- Maritime professionals
- Port operators
- Students and academics
- Weather and climate enthusiasts

## Core Features

1. Interactive Map

Visualize oceanographic datasets on an interactive map with multiple basemaps, dynamic layers, and customizable markers.

Features
Interactive Leaflet map
CSV data visualization
Marker customization
Time filtering
Popups and tooltips
Layer controls

2. Particle Tracer

Track particle or buoy movement using latitude, longitude, and timestamp information.

Features
Trajectory visualization
Animated movement
Timeline filtering
Configurable marker and line styles

3. Wind Rose

Analyze wind direction and wind speed distributions through interactive wind rose diagrams.

Features
Wind direction frequency
Wind speed classification
Interactive visualization
Exportable charts

4. Wave Analysis

Analyze wave characteristics from observational or model datasets.

Features
Significant Wave Height (Hs)
Wave Period
Wave Direction
Time-series visualization
Statistical summaries

5. Tidal Analysis

Analyze tidal observations and tidal predictions.

Features
Water level visualization
Tidal constituents
Harmonic analysis
Time-series charts

6. Climatology

Visualize large-scale climate indicators that influence ocean conditions.

Features
Oceanic Niño Index (ONI)
Dipole Mode Index (DMI)
Sea Surface Temperature (SST)
Sea Level Anomaly (SLA)

### Data Management

Import, process, filter, and export oceanographic datasets.
